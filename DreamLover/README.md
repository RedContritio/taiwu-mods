# 梦中情人 DreamLover

NPC 主动对太吾产生爱慕、表白与求婚。

## 功能

### 主动爱慕

NPC 在过月时主动对太吾产生倾心爱慕。

### 主动表白

已经爱慕太吾的 NPC 在月初主动向太吾表白，成为两情相悦关系。

### 主动求婚

与太吾两情相悦的 NPC 在月初主动求婚。

- 已婚人士：保留设置；当前正式版婚姻规则仍会阻止已婚 NPC 结婚
- 太吾多配偶制：保留设置；当前正式版婚姻规则仍会阻止太吾重婚
- 出家人：允许出家身份的 NPC 求婚
- 太吾出家也要求婚：NPC 无视太吾出家身份

### 心去难留

当主动爱慕和主动表白都关闭时生效。襄王有意，神女无心——不被太吾回应的单恋者将在过月时断绝爱慕。

### 通用筛选条件

| 筛选维度 | 说明 |
|---------|------|
| 性别 | 是否接受同性（默认仅异性） |
| 年龄范围 | 可接受的年龄上下限 |
| 好感度 | 血仇～不渝（13级） |
| 魅力 | 非人～天人（9级） |
| 立场 | 刚正、仁善、中庸、叛逆、唯我 |
| 关系类型 | 允许哪些与太吾有特定关系的 NPC 追求，按太吾视角命名（默认阻止血亲/义亲） |
| 地理限制 | 爱慕是否受同地块限制 |
