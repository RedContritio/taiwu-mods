# 爱慕系统 (Adored, RelationType 0x4000 = 16384)

## 概述

爱慕是单向关系。A 爱慕 B 不代表 B 爱慕 A。
当 A 爱慕 B 且 B 也爱慕 A 时，称为"两情相悦"(双向 Adored)。
