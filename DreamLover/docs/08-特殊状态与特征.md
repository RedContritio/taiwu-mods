FUNCTION GetAgeGroup(age):               // 入参: short

### 关键方法伪代码

```
FUNCTION HasRelation(currTypes, targetType):
    RETURN (currTypes & targetType) != 0

FUNCTION IsOneWayRelation(relationType):
    RETURN relationType == 16384 (Adored) OR relationType == 32768 (Enemy)

FUNCTION GetOppositeRelationType(relationType):
    // 反向关系映射
    BloodParent  <=> BloodChild
    StepParent   <=> StepChild
    AdoptiveParent <=> AdoptiveChild
    Mentor       <=> Mentee
    // 以下为自身对称:
    BloodBrotherOrSister, StepBrotherOrSister, AdoptiveBrotherOrSister,
    SwornBrotherOrSister, HusbandOrWife, Friend
    // 单向关系无反向:
    Adored => General, Enemy => General

FUNCTION ContainDirectBloodRelations(relationTypes):
    RETURN (relationTypes & 0x0007) != 0
    // 检测: BloodParent(1) | BloodChild(2) | BloodBrotherOrSister(4)

FUNCTION ContainNonBloodFamilyRelations(relationTypes):
    RETURN (relationTypes & 0x03F8) != 0
    // 检测: StepParent(8) ~ AdoptiveBrotherOrSister(256)

FUNCTION IsFamilyRelation(relation):
    RETURN (relation & 0x05FF) != 0
    // 检测: 所有家庭关系 + 配偶 (排除 Mentor/Mentee/Friend/Adored/Enemy)

FUNCTION IsFriendRelation(relation):
    RETURN (relation & 0x6200) != 0
    // 检测: SwornBrotherOrSister(512) | Friend(8192) | Adored(16384)

FUNCTION ContainPositiveRelations(relationTypes):
    RETURN (relationTypes & 0x7FFF) != 0
    // 检测: 除 Enemy(32768) 外所有

FUNCTION ContainNegativeRelations(relationTypes):
    RETURN (relationTypes & 0x8000) != 0
    // 检测: 仅 Enemy(32768)

FUNCTION ContainsNonRemovableRelations(relationTypes):
    RETURN (relationTypes & 0x013F) != 0
    // 检测: BloodParent(1) ~ AdoptiveChild(128) (不可解除的家庭关系)

FUNCTION ContainBloodExclusionRelations(relationTypes):
    RETURN (relationTypes & 0x07FF) != 0
    // 检测: 所有家庭关系 + 配偶 (用于排斥血亲)

FUNCTION NeedRecordOnRemoval(relationType):
    RETURN relationType == 64 (AdoptiveParent)
        OR relationType == 128 (AdoptiveChild)
        OR relationType == 1024 (HusbandOrWife)
```

## 7. Feature 一览

### 恋爱忠诚度 (Feature 162-167)

影响 CalcAdoreMultiplePeopleChanceFactor 函数的返回值。该函数在以下两处被调用:
1. SexRelationBaseRate -- 计算目标已有爱慕者的惩罚
2. GetStartOrEndRelationChance (TemplateId=2) -- 计算 AI 是否尝试发起爱慕

AdoreMultiplePeopleChanceFactor 值（数据来源: CharacterFeature 配置表）:

| Feature ID | 名称 | AdoreMultiplePeopleChanceFactor | 效果 |
|-----------|------|-------------------------------|------|
| 162 | 情有独钟 | ~80 | 缩小已有爱慕者惩罚，更专一 |
| 163 | 从一而终 | ~60 | 进一步缩小惩罚 |
| 164 | 忠贞不渝 | ~40 | 惩罚缩至最小 |
| 165 | 三心二意 | ~120 | 放大已有爱慕者惩罚（绝对值） |
| 166 | 见异思迁 | ~140 | 进一步放大 |
| 167 | 朝三暮四 | ~160 | 惩罚放至最大 |

注: 因为 StartAdoreChanceChangePerAdored 为负值, factor > 100 意味着"每个已有爱慕者造成的概率下降更多", 即这个角色更不容易在已有爱慕者的情况下再被爱慕。factor < 100 则相反。

计算示例:
- 中庸角色(2), 已有 2 个爱慕者, 无特殊特征:
  `2 * (-30) * 100 / 100 = -60`
- 中庸角色(2), 已有 2 个爱慕者, 拥有"忠贞不渝"(factor=40):
  `2 * (-30) * 40 / 100 = -24`
- 中庸角色(2), 已有 2 个爱慕者, 拥有"朝三暮四"(factor=160):
  `2 * (-30) * 160 / 100 = -96`

## 11. GetStartOrEndRelationChance 中的关系基础概率选择

第 558782-558783 行, 根据当前双方已有关系类型选择不同的概率基数:

```
IF ContainDirectBloodRelations(curRelationType)        // 血亲
   OR HasRelation(curRelationType, 1024):               // 配偶
    adjust += Probability[behaviorType].BloodRelationsProb

ELSE IF ContainNonBloodFamilyRelations(curRelationType) // 非血亲家属
        OR HasRelation(curRelationType, 2048)            // 师父
        OR HasRelation(curRelationType, 4096):           // 徒弟
    adjust += Probability[behaviorType].SwornOrAdoptiveRelationsProb

ELSE:                                                   // 无特殊关系
    adjust += Probability[behaviorType].DefaultProb
```

最终返回: `Max(0, adjust * chanceMul * multiplier / 100)`

这三列概率值 (BloodRelationsProb, SwornOrAdoptiveRelationsProb, DefaultProb) 来自 AiRelations 配置表, 按 TemplateId 和 BehaviorType 索引, 具体值需查阅数据表。
