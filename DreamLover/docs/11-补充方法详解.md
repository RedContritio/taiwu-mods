## 2. 血亲位掩码对比

| 方法 | 位掩码 | 覆盖范围 | 用途 |
|------|--------|----------|------|
| `ContainDirectBloodRelations` | 0x0007 | 亲生父母(1)+亲生子女(2)+亲生兄妹(4) | 恋爱概率惩罚(-160) |
| `ContainNonBloodFamilyRelations` | 0x03F8 | 继亲(8,16,32)+义亲(64,128,256)+结义(512) | 恋爱概率惩罚(-80) |
| `ContainBloodExclusionRelations` | 0x07FF | 上述全部+配偶(1024) | 婚姻完全阻止 |

注意：`ContainBloodExclusionRelations` 的 0x7FF 实际包含了关系类型 1-1024 的所有位，包括配偶位。

### 处理单个事件链

```pseudocode
FUNCTION ProcessEventWithDefaultOption(eventGuid, eventArgBox, behaviorType):

    visitedEvents = new HashSet()  // 防止循环

    WHILE eventGuid 不为空:
        IF 已访问过此事件: 抛出循环异常

        event = GetEvent(eventGuid)

        // 条件检查
        IF NOT event.CheckCondition(): BREAK

        event.OnEventEnter()

        // 寻找匹配太吾行为类型的选项
        IF event 有标准选项:
            FOR EACH option IN event.EventOptions:
                optionBehavior = EventOptionBehavior.ToBehaviorType[option.Behavior]
                IF optionBehavior == behaviorType:
                    eventGuid = option.Select()  // 执行选项，返回下一个事件
                    BREAK
            IF 无匹配选项: eventGuid = ""  // 终止链
        ELSE IF event 有退出选项:
            eventGuid = event.EscOption.Select()  // 使用退出路径

        event.OnEventExit()
```

**关键机制：**
- 月报事件按太吾当前行为类型（刚正/仁善/中庸/叛逆/唯我）自动选择对应选项
- 事件可以链式触发（一个事件的选项指向下一个事件）
- 有循环检测防止无限链
- 特殊/锁定事件必须玩家手动处理

## 6. HasNominalBloodRelation（名义血亲检查）

源码: `GameData.decompiled.cs` L510005-510027

```pseudocode
FUNCTION HasNominalBloodRelation(charId, relatedCharId, relation) -> bool:

    // 第一层: 直接关系检查
    L510007: IF relation.RelationType != 0xFFFF
             AND ContainDirectBloodRelations(relation.RelationType):
               RETURN true  // 直接血亲

    // 第二层: 遍历 charId 的家族网络
    L510011: IF 有 charId 的关系网络:
               // 检查 relatedCharId 是否在 charId 的血亲父母集合中
               IF HasNominalDirectBloodRelation(charId.BloodParents, relatedCharId, false):
                   RETURN true
               // 检查 relatedCharId 是否在 charId 的血亲兄妹集合中
               IF HasNominalDirectBloodRelation(charId.BloodSiblings, relatedCharId, false):
                   RETURN true
               // 检查 relatedCharId 是否在 charId 的血亲子女集合中
               IF HasNominalDirectBloodRelation(charId.BloodChildren, relatedCharId, true):
                   RETURN true  // exceptBloodParent=true: 排除父母关系

    RETURN false
```

**与 ContainDirectBloodRelations 的区别：**
- `ContainDirectBloodRelations`: 只检查一个 ushort 位掩码，判断是否有直接血亲位
- `HasNominalBloodRelation`: 遍历角色的整个家族网络（父母集合、兄妹集合、子女集合），找隐藏的血缘关系
- **用途**：婚姻合法性检查必须用 HasNominalBloodRelation，因为通过收养可能隐藏真实血缘
