# 表白系统 (BoyOrGirlFriend, 双向 Adored)

## 概述

表白是将单向爱慕升级为双向爱慕 (两情相悦) 的过程。游戏内称为"表露心事"。
发起者已爱慕目标，通过表白使目标也爱慕自己。表白有成功和失败两条分支。

## 月度处理

- 目标是太吾时: `monthlyEventCollection.AddConfess(charId, location, taiwuId)` -- 产生月报事件"表露心事"，由玩家在月报中处理
- 目标非太吾时: 直接调用 `ApplyBecomeBoyOrGirlFriend`，由 AI 自动处理

**注意:** 爱慕用 `AddAdore`，表白用 `AddConfess`，两者是不同的月报事件类型。
