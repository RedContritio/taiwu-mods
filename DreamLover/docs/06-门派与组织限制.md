# 门派与组织限制

## 1. 核心判定 -- OrgAndMonkTypeAllowMarriage

源码位置: `GameData.decompiled.cs:526953-526956`

```
function OrgAndMonkTypeAllowMarriage():                          // :526953
    return _monkType == 0                                        // :526955  非出家人
        && OrganizationDomain.GetOrgMemberConfig(_organizationInfo).ChildGrade >= 0  // :526955  组织允许婚嫁
```

这是最核心的婚嫁许可判定, 被多个系统引用。两个条件必须同时满足:
1. `MonkType == 0` (不是出家人)
2. `ChildGrade >= 0` (组织阶层允许生育/婚嫁)

## 6. 各门派婚嫁规则

### 限制机制分类

| 门派 | 限制机制 | 说明 |
|------|----------|------|
| 璇女派 | `ChildGrade < 0` | 所有弟子禁止婚嫁, 通过组织配置实现 |
| 五仙教 | `ChildGrade < 0` (仅上三阶) | 按阶层限制, 低阶弟子不受限 |
| 少林派 | `MonkType != 0` | 出家弟子通过 MonkType 禁止, 俗家弟子不受限 |
| 峨眉派 | `MonkType != 0` | 出家弟子禁止, 俗家弟子不受限 |
| 武当派 | `MonkType != 0` | 出家修道之人禁止 |
| 其他门派 | 无限制 | ChildGrade >= 0 且 MonkType == 0 |

### 影响范围对比
