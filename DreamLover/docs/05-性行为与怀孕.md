function GetMakeLoveRole(random, ref father, ref mother):
    hasBisex_f = father.GetFeatureIds().Contains(170)            // :527322
    hasBisex_m = mother.GetFeatureIds().Contains(170)            // :527323

    // 同性且无双性特征 -> 不可发生
    if !hasBisex_f && !hasBisex_m && father.GetGender() == mother.GetGender():  // :527324
        return false                                             // :527326

    // 判断是否需要互换角色:
    // - 若 father 无双性特征 -> father 是女性时互换 (father.Gender==0)
    // - 若 father 有双性特征但 mother 无 -> mother 不是女性时互换 (mother.Gender!=0)
    // - 双方都有双性特征 -> 50% 随机
    needSwap = (!hasBisex_f) ? (father.GetGender() == 0)         // :527331
             : (!hasBisex_m) ? (mother.GetGender() != 0)
             : random.CheckPercentProb(50)

    if needSwap:                                                 // :527335
        swap(father, mother)                                     // :527337-527340
    return true                                                  // :527342

## 5. 怀孕判定 -- PregnantState.CheckPregnant

源码位置: `GameData.decompiled.cs:550501-550547`

```
function CheckPregnant(random, father, mother, isRape):
    baseChance = isRape ? 20 : 60                               // :550503  基础概率: 合法60% / 强制20%
    fatherId = father.GetId()                                    // :550504
    motherId = mother.GetId()                                    // :550505

    // === 阻止条件 ===
    if !CheckMakeLoveRole(father, mother):                       // :550506
        return false                                             // :550508
    if mother.HasFeature(198):                                   // :550510  已怀孕
        return false                                             // :550512
    if PregnancyLockEndDates.Contains(motherId):                 // :550514  怀孕锁定期
        return false                                             // :550516

    // === 子嗣数量限制 ===
    taiwuId = Taiwu.GetTaiwuCharId()                             // :550518
    isTaiwuInvolved = (motherId == taiwuId || fatherId == taiwuId)  // :550519
    divisor = isTaiwuInvolved ? 20 : 40                          // :550520
    // 太吾参与时除数=20 (每20点生育力允许1个孩子)
    // 纯NPC时除数=40  (每40点生育力允许1个孩子)

    fatherFertility = father.GetFertility()                      // :550521
    fatherChildCount = GetRelatedCharIds(fatherId, 2).Count      // :550522  关系类型2 = 亲生子女
    if fatherFertility / divisor < fatherChildCount:             // :550523  整数除法, 严格小于时阻止
        return false                                             // :550525
        // 注意: fertility/divisor == count 时不阻止 (允许再生一个)

    motherFertility = mother.GetFertility()                      // :550527
    motherChildCount = GetRelatedCharIds(motherId, 2).Count      // :550528
    if motherFertility / divisor < motherChildCount:             // :550529
        return false                                             // :550531

    // === 概率计算 ===
    if isTaiwuInvolved:                                          // :550533
        return random.CheckPercentProb(baseChance * fatherFertility * motherFertility / 10000)  // :550535

    // 纯NPC路径:
    prob = baseChance * fatherFertility * motherFertility / 10000  // :550537
    if father.OrgTemplateId == 16 || mother.OrgTemplateId == 16: // :550538  OrgTemplateId 16 = 流浪者
        homelessCount = Building.GetHomeless().GetCount()         // :550540
        if homelessCount > 0:                                    // :550541
            prob = prob / (10 * homelessCount)                   // :550543  大幅降低流浪者生育概率
    return random.CheckPercentProb(prob)                         // :550546
```

### 怀孕概率公式

```
最终概率 = baseChance * fatherFertility * motherFertility / 10000

其中:
  baseChance = 60 (合法) 或 20 (强制)
  fatherFertility, motherFertility: [0, 32767] 范围内的 short
  
举例: 双方生育力各100, 合法 -> 60 * 100 * 100 / 10000 = 60%
举例: 双方生育力各50, 强制  -> 20 * 50 * 50 / 10000 = 5%

流浪者额外惩罚: prob /= (10 * 流浪者总数)
```

### 子嗣上限公式

```
上限 = fertility / divisor  (整数除法, 向下取整)
divisor = 20 (太吾参与) 或 40 (纯NPC)

举例: 生育力100, 太吾参与 -> 可有 100/20=5 个孩子
举例: 生育力100, 纯NPC    -> 可有 100/40=2 个孩子
举例: 生育力39,  纯NPC    -> 可有 39/40=0 个孩子 (不能生育)

阻止条件: fertility/divisor < 已有子嗣数 (严格小于, 等于时仍可再生一个)
```
