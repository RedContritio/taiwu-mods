# 观音识蛐蛐

> 又名「蛐蛐叫声品级染色」。


太吾绘卷「捕捉蛐蛐」小游戏里，每个草丛位置的蛐蛐鸣叫时会弹出一个白色涟漪「圈」，叫声的**音高**与**圈大小（可视音量感）**隐含了这只声音的品级，但靠耳朵分辨对很多玩家有难度。

本 Mod 直接把这个涟漪圈按「**声音对应的品级**」染上颜色，让玩家一眼分辨；同样的染色也覆盖**斗蛐蛐、收藏罐**等会画出某只具体蛐蛐叫声圈的地方（见下「覆盖范围」）。

## 它做什么

- 在 `ViewCatchCricket.ShowCricketSingImage` 上挂一个 Harmony Postfix：原版刚把涟漪圈设成白色，本 Mod 立即把圈的颜色改成「声音品级」对应色，**只改 RGB、保留 alpha**，所以原版的淡出动画照常工作。
- 「声音品级」由每只蛐蛐**固定**的两个声音参数合成：声音分 = `SingPitch`（音高）+ X × `SingSize`（涟漪圈基础大小 / 响度感），其中权重 X 由设置档位决定（默认 3）。
- 合成分按**品级锚定**校准映射到品级档：从 `CricketParts` 配置按游戏规则重建所有可捕捉蛐蛐（颜色+部件，品级取两者最大、声音取两者之和），算出**每个真实品级典型的声音分**作为锚点；某位置的叫声分到**最接近的那个品级**，再上对应的**游戏自带 9 档品级配色 `Colors.GradeColors`**——即游戏在技艺/势力/物品、以及抓到后蛐蛐名字处显示品级用的同一套颜色，所以圈色与游戏的品级语言完全一致。
- 因为这两个参数对同一只蛐蛐固定不变，所以**同一位置的圈颜色稳定**，不会逐次闪烁。

> 实测：约 **4/5 的蛐蛐圈色落在真实品级 ±1 档内**；剩下的差距大多是游戏故意设计的「声音陷阱」（响亮的 Trash、安静的 King、低色+高品级部件等）——它们如实显示「听起来的品级」，与真实品级不同，这正是本 Mod 的本意。详细分项见下「准确率（实测统计）」。

## 覆盖范围

凡是会画出**某只具体蛐蛐**叫声圈的界面都一并染色（共用同一套声音品级逻辑）：

- **捕蛐蛐小游戏**（`ViewCatchCricket.ShowCricketSingImage`）——野外草丛的 21 个位置。
- **斗蛐蛐盒子 / 收藏罐 / 物品·图鉴 tooltip / 预览窗 / 事件选择**（`CricketView.Sing`、`CricketViewNew.Sing` 两个卡片视图）。
- 地图上的「玩物」蛐蛐用的是占位数据（`SetCricketData(0,0)`，永远 0 品），染了无意义，**不染**。

**关于斗蛐蛐里的对手**：对手的三只蛐蛐由游戏按对手门派品级**现场生成**，因此——

- 打**高品对手**（门派掌门/长老等）时对手圈色往往五颜六色；打**低品杂鱼**时，现场生成的三只可能都是 0 品「呆物」、清一色同色。这是对手实力的真实反映，**不是染色出错**。
- 圈色**不被「是否鉴定」遮挡**：对手名字显示「未知」只是遮了名字，叫声圈仍按蛐蛐真实颜色/品级正常染色（呈现的是它的声音品级）。

## 准确率（实测统计）

下列数字基于离线重建**全部 颜色×部位 = 2944 个**可捕捉蛐蛐组合（与品级锚定校准同一口径），统计圈色（声音品级）与真实品级的命中率。

**三档预设几乎一样准**（差别在 1% 以内，所以选哪档对准确率没影响，只是边界上极少数蛐蛐挪一格）：

| 预设（音高 : 圈大小）| 精确命中 | 误差 ≤1 品 |
|---|---|---|
| 音高优先 1:2 | 35.1% | 78.6% |
| 均衡 1:2.5 | 34.3% | 78.6% |
| 音量优先 1:3（默认）| 34.0% | 79.3% |

**按真实品级（默认 1:3；品级 1 最高 / 9 最低）——两头准、中间糊**：

| 真实品级 | 样本(组合) | 精确 | ≤1 品 |
|---|---|---|---|
| 9 品（垫底）| 55 | 98% | 98% |
| 8 品 | 162 | 67% | 100% |
| 7 品 | 270 | 58% | 96% |
| 6 品 | 570 | 44% | 85% |
| 5 品 | 684 | 26% | 75% |
| 4 品 | 852 | **15%** | 78% |
| 3 品 | 324 | 33% | 52% |
| 2 品 | 6 | 50% | 100% |
| 1 品（最强）| 21 | 62% | 86% |

- **精确率约 34% 是设计使然**，不是缺陷：圈色显示「声音品级」，而游戏故意让一批蛐蛐声音 ≠ 真实品级（声音陷阱）。**误差 ≤1 品 约 79%** 才是“大致看得准”的指标。
- **垫底（9 品 98%）和顶级（1 品 62%）最容易认；中段 4–5 品 最糊（15–26%）**——大量不同蛐蛐的声音分挤在一起，靠耳朵在这儿也最难分。
- 统计每种组合等权、未按野外刷新概率加权，实际体验略有出入；但“两头准、中间糊”的分项规律不受此影响。

## 它不做什么

- **不读取也不显示蛐蛐的真实等级 `CricketLevel`**——颜色表示「声音透露出来的品级」，不是直接剧透答案。因此圈色（声音品级）与抓到后名字的真实品级色可能不同。
- 不改音量、音高、圈大小、捕捉成功率、蛐蛐品级或任何后端数值；纯前端、纯显示。
- 不加自启用总开关（由游戏「模组管理」负责启停）。

## 设置项 / 默认参数

- **声音品级权重** —— 可在游戏「模组管理」里调，**三档下拉框**：**音高优先（1:2）/ 均衡（1:2.5）/ 音量优先（1:3，默认）**。三档都落在实测有效区间（1:2~1:3）内，准确度几乎相同（见上「准确率」），区别只是边界上极少数蛐蛐挪一格。**改动即时生效**，无需重启。
- 品级数 = 9，调色板 = 游戏自带 `Colors.GradeColors`（`UseGameGradeColors = true`，见 `SoundGradeConfig.cs`）；读取不到时回退到内置 9 档品级色带（灰→白→绿→浅蓝→青→紫→金→橙→红）。
- 校准：**品级锚定**——叫声分映射到最接近的真实品级锚点（声音越响 → 品级越高，由数据决定）。
- `DebugLog`（`SoundGradeConfig.cs`，默认关）：开启后向 Player.log 输出一次校准摘要（调色板来源 / 品级数 / 每品级锚点分）。

## 兼容性

- 纯前端 Harmony 补丁，作用于捕蛐蛐小游戏及各蛐蛐卡片视图（斗蛐蛐 / 收藏罐 / tooltip / 预览等，见「覆盖范围」）；其余玩法不受影响。
- 校准失败或异常时会安全跳过染色（圈保持原版白色），不会影响小游戏运行。
