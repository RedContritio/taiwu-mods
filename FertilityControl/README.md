# 子嗣掌控 FertilityControl

控制太吾与他人发生关系时的生育参数。

## 功能

| 选项 | 说明 |
|------|------|
| 指定总生育能力 | 覆盖最终生育能力乘积为指定值 (0~15000)，仍保留正式版子嗣上限 |
| 指定父方生育能力 | 单独设定父方的生育能力 |
| 指定母方生育能力 | 单独设定母方的生育能力 |
| 指定怀孕概率 | 直接设定怀孕成功率 (%) |
| 指定蛐蛐概率 | 设定异胎（蛐蛐）出生率 (%) |
| 禁止近亲畸形 | 太吾参与的近亲生育不会产生先天畸形 |

指定总生育能力优先生效；开启时父方/母方单独设定会被忽略。

## 设置

### 存档级（跟随存档，不同存档可不同）

| 设置 | 类型 | 默认值 |
|------|------|--------|
| 指定总生育能力 | 开关 | 关 |
| 总生育能力值 | 滑块 | 7500 |
| 指定父方生育能力 | 开关 | 关 |
| 父方生育能力值 | 滑块 | 100 |
| 指定母方生育能力 | 开关 | 关 |
| 母方生育能力值 | 滑块 | 100 |
| 指定怀孕概率 | 开关 | 关 |
| 怀孕概率 | 滑块 | 50% |
| 指定蛐蛐概率 | 开关 | 关 |
| 蛐蛐概率 | 滑块 | 10% |
| 禁止近亲畸形 | 开关 | 关 |

### 游戏级（全局生效，所有存档共用）

| 设置 | 类型 | 默认值 |
|------|------|--------|
| 调试模式 | 开关 | 关 |

## 架构

纯后端 Mod。补丁目标为生育判定相关方法。
