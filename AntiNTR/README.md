# 防绿 AntiNTR

防止与太吾有特定关系的 NPC 的配偶与他人发生关系。

## 功能

| 选项 | 说明 |
|------|------|
| 启用 | 开关，关闭时补丁放行所有行为 |
| 能与配偶发生关系 | 被保护者的配偶仍可与其合法配偶发生关系 |
| 控制的关系 | 选择哪些关系类型的 NPC 受到保护，会同时检查太吾到 NPC 与 NPC 到太吾两个方向 |
| 任何人 | 保护所有 NPC（非太吾双方均无法发生关系） |

## 设置

### 存档级（跟随存档，不同存档可不同）

| 设置 | 类型 | 默认值 |
|------|------|--------|
| 启用防绿 | 开关 | 开 |
| 能与配偶发生关系 | 开关 | 开 |
| 知心之交 | 开关 | 关 |
| 亲生兄妹 | 开关 | 关 |
| 亲生父母/子女 | 开关 | 关 |
| 继父母/继子女/继兄妹 | 开关 | 关 |
| 义父母/义子女/义亲兄妹 | 开关 | 关 |
| 授业恩师 | 开关 | 关 |
| 义结金兰 | 开关 | 关 |
| 嫡系传人 | 开关 | 关 |
| 敌对 | 开关 | 关 |
| 结发夫妻 | 开关 | 开 |
| 爱慕 | 开关 | 开 |
| 任何人 | 开关 | 关 |

### 游戏级（全局生效，所有存档共用）

| 设置 | 类型 | 默认值 |
|------|------|--------|
| 调试模式 | 开关 | 关 |

## 架构

纯后端 Mod。补丁目标为 NPC 离线发生关系与过月固定行为补全阶段。
