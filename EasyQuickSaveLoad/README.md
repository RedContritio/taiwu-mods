# EasyQuickSaveLoad

在游戏内按 ESC 打开的系统面板里添加一组按钮：

- 存档：第一次点击会展示即将保存的世界摘要、已有手动存档数量；如果手动存档已满，还会展示将被覆盖的最旧手动存档。再次点击确认后，在同一太吾世界下创建 EasyQuickSaveLoad 独立手动存档。保留数量复用原生“回溯备份数量”设置，但不占用原生 `.bak` 回溯文件。
- 读档：复用太吾原生回溯列表 UI，但标题会标记为 EasyQuickSaveLoad 手动读档；列表内容来自 EasyQuickSaveLoad 独立手动存档，不读取原生 `.bak` 回溯。
- 快速存档：第一次点击会展示将被覆盖的当前主档信息；再次点击确认后覆盖当前主档。
- 快速读档：第一次点击会展示当前主档的保存时间、太吾、年数和地点；再次点击确认后，直接重新载入当前主档，不需要回到主菜单。

按钮只会在游戏内 ESC 系统面板处于焦点时显示。存档数据未加载完成、Loading、月结、战斗、事件窗口和正在保存时会禁用操作。
