# EasyQuickSaveLoad

galgame 式的栏位存档系统：一个独立的**快捷存档栏** + N 个可寻址的**普通存档栏**，各栏可单独存 / 读 / 删。入口是游戏内按 ESC 打开系统面板时，在其**右侧**出现的一组原生风格「快速 SL」按钮面板（面板只在系统面板处于焦点时显示，关闭菜单即消失，不改动原生系统菜单本身）。

面板含四个按钮，分两组：

- **快速存档 / 快速读档**：操作独立的**快捷栏**（不进选栏面板）。快速存档覆盖快捷栏；快速读档直接重载快捷栏、无需回主菜单。两者可在设置里各自开关确认弹窗；确认弹窗用游戏原生对话框，显示该存档的保存时间 / 太吾 / 年数 / 地点。快捷栏为空时快速读档不动作。
- **存档 / 读档**：打开一个自建的模态**选栏面板**——可滚动、每行两个的 N 格网格（N = 设置「普通存档栏位数」）。每格显示：备注名（若设置了）/ 保存时间 / 太吾 / 年数；最近一次保存的栏位标【最新】，空栏显示（空）。每格右侧有**改名**和**删除**两个原生风格图标按钮（空栏时禁用）。
  - 存档模式：点空栏直接存；点已有存档的栏先确认覆盖再存。
  - 读档模式：点已有存档的栏，确认后读取。
  - 删除、覆盖、读取的二次确认都是面板内的确认层。

## 存储

- 每个普通栏是独立文件 `local.sav.qsl.slot.<N>`，快捷栏是 `local.sav.qsl.quick`，都存在当前太吾世界的存档目录下，**不占用、不读写游戏原生的 `.bak` 回溯文件**，也不触碰主档 `local.sav`。
- 每栏的备注（改名）单独存在 `local.sav.qsl.notes`；覆盖或删除某栏时会清掉该栏的旧备注。

## 设置项

- **普通存档栏位数**（`SlotCount`，默认 20，范围 1–99）：选栏面板里的普通栏数量。
- **快速存档需要确认**（默认开）：快速存档前是否弹确认框。
- **快速读档需要确认**（默认开）：快速读档前是否弹确认框。

## 可用性

面板按钮只在系统面板处于焦点时显示。存档数据未加载完成、Loading、月结、战斗、事件窗口和正在保存时，按钮会置灰禁用。
