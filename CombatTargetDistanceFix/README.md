# 战斗距离目标修复

修复太吾绘卷正式版战斗中**目标距离条偶尔不可交互、无法用鼠标移动目标距离**的问题。

## 距离条交互机制（背景）

战斗下方的目标距离条是否可拖动，由前端 `ViewCombat.UpdateTargetDistanceInteract` 决定：

```
可交互 = (未自动战斗 || 未自动移动) && 当前可操作自身角色
```

要点：

- 距离条进入「不可交互(Invalid)」状态**只**由 `SetInteract(false)` 触发，而它**只**在四处被调用：战斗初始化、`CombatPrepared`、AI 选项变化、切换自动战斗。
- 一旦进入 Invalid，鼠标悬停（OnPointerEnter）会被 `_interactType != Invalid` 守卫挡住，**距离条无法自行恢复**——必须再有一次刷新把它重新置为可交互。
- 距离条只有在 `_interactType == Self`（鼠标确实压在条上）时，按住鼠标才会调用 `SetTargetDistance` 真正移动目标距离。

这套机制下有三个会让玩家「明明该能拖、却拖不动」的缺陷，本 Mod 各打一个补丁。

## 修复的场景

### 场景一（主要、最常见）：悬停时一次刷新把距离条「打死」

- **现象**：战斗中鼠标正停在距离条上，恰好发生一次交互状态刷新（例如切换自动战斗、改 AI 选项等），距离条突然变得按不动；要把鼠标完全移开再移回来才恢复。这就是玩家常说的「距离条偶尔点不动」。
- **根因**：`CombatDistanceBar.UpdateInteractType()`（无参版）用 `RectTransformUtility.RectangleContainsScreenPoint` 做鼠标命中检测时**没有传入 UI 相机**。战斗 UI 画布是 Screen Space - Camera（事件相机 `Camera_UIRoot`，且画布 2560×1440 与实际 3840×2160 屏幕存在缩放），不带相机的命中检测会把「鼠标其实在条上」误判成「不在」，于是把本应保持的 `Self` 错置为 `None`，距离条在光标下失效。（同类的 `CalcPreviewTarget` 用了 `UIManager.UiCamera`，是正确写法——对照即知。）
- **补丁**：用 Transpiler 把那次命中检测替换为带 `UIManager.Instance.UiCamera` 的版本。

### 场景二：当前操作角色切换后交互状态未刷新

- **现象**：当前被操作的自身角色发生切换（车轮战式轮换、或下达「参战」协战指令换人）后，距离条的可交互状态没有跟随新角色刷新，可能与实际可操作性不同步。
- **根因**：`ViewCombat.ChangeCombatChar` 协程在结束时**没有调用** `UpdateTargetDistanceInteract`。
- **补丁**：用 Postfix 包裹该协程，结束后重新刷新距离条交互状态。

### 场景三：当前角色协战指令变化后交互状态未刷新

- **现象**：当前被操作角色的协战指令（`ExecutingTeammateCommand`）发生变化后，距离条的可交互状态没有跟随刷新。
- **根因**：`ViewCombat.OnExecutingTeammateCommandChanged` 更新了自动战斗标记和动作按钮，但**没有刷新**距离条。
- **补丁**：用 Postfix 在该方法后重新刷新距离条交互状态。

> 关于场景二/三：在当前游戏逻辑下，被玩家操作的自身角色**始终是可操作的**（成为被操作角色与「可操作」是同一笔操作），主角被打倒会直接判负而非轮换，因此这两种「应可交互却卡死」的状态在正常玩法里几乎触发不到——这两个补丁更多是**防御性**地保证交互状态始终与当前角色同步。场景一才是玩家实际会遇到的高频问题。

## 与键盘 A / D 移动的关系

战斗中除了拖动距离条，还能**长按 A / D 键移动**（A=拉远、D=拉近）。

这条路径与距离条**完全独立**：A/D 走的是 `CombatDomainMethod.Call.SetMoveState`，只受「当前可操作自身角色」和「战斗未暂停（TimeScale>0）」限制，**从不读取距离条的交互状态**。

因此：

- **即使距离条卡死、拖不动，玩家依然可以用 A/D 键移动**（实测：距离条处于 Invalid 时按 D 仍能让太吾前移）。
- 本 Mod **不改动** A/D 移动的任何行为；A/D 既不受这个 bug 影响，也不受本修复影响。

## 边界

- 本 Mod 不改变自动战斗和自动移动的语义。自动战斗且开启自动移动时，目标距离仍由原版逻辑接管，距离条保持不可交互。
- 本 Mod 只刷新/修正前端距离条的**交互状态与鼠标命中检测**，不修改后端战斗距离、移动结算、移动消耗、跳跃阈值、功法效果或战斗指令接受规则。
- 不影响键盘 A/D 移动、不影响敌方距离、不改变任何战斗数值。

## 验证情况

- **场景一（相机命中检测）已在游戏内双向实测确认**：无本 Mod 时，鼠标停在条上触发一次刷新即把 `_interactType` 由 `Self` 翻成 `None`、按住鼠标不改变目标距离（拖不动）；启用本 Mod 后，同样操作下 `_interactType` 保持 `Self`、按住即设置目标距离（可正常移动）。
- **场景二/三的补丁接线已实测确认**：在距离条被置为 Invalid 后触发对应事件，无本 Mod 时距离条保持 Invalid（仍拖不动），启用本 Mod 后 Postfix 会重新刷新、距离条恢复可交互、可正常设置目标距离。
- A/D 键移动独立于本 bug 与本修复，已实测确认。
