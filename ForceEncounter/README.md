# 情难自已 ForceEncounter

为玩家提供一个正式版接口，在互动菜单里主动触发角色之间的强制行为。

开发决策和原生路径调查记录见 [docs/development-notes.md](docs/development-notes.md)。

## 功能

### 敌对互动选项

通过正式版事件包和 `InteractionEventOption` 配置，在角色互动菜单的「敌对」子项中加入「情难自已」。选择目标 NPC 后，默认以太吾为行为者、当前 NPC 为目标。

外层选项标记为「唯我」以保持敌对菜单风格，并只用 `AutoConsume=false` 的 `OptionConsumeInfo` 预览行动力成本；它通过原生 wait-confirm 机制延迟外层行为效果，因此点击进入内层时不会立刻扣心情，也不会消耗行动力。真正校验和消耗发生在内层提交选项，内层提交使用 `AutoConsume=true`，并确认外层 wait 选项；选择“其他话题”不会确认外层 wait。行动力消耗可配置为 0 到 5 天，设为 0 时不显示成本也不消耗。点击后会先判定当前关系是否可以不进入战斗。内层说明会显示“行为者对目标情难自已”的动作摘要。

亲密直通来源包括配偶、双向爱慕、目标单恋太吾、太吾村民、以及原生 `谷中密友` 特性 `685`。配偶、双向爱慕、单恋太吾会按恋人类难度进入亲密判定；村民在未心有所属他人时享受好感门槛降低；谷中密友若未心有所属他人可进入亲密判定，若已心有所属他人，则目标对太吾好感必须高于原生 `Favorite2 / 融洽` 才能亲密豁免。若不能直通，会进入强制关系的内层提交分支：玩家可以选择强行开战，也可以回到其他话题。未成年不会多一层确认，也不会改变内层选项，只会替换内层说明文本。成年亲密、未成年亲密、成年强制、未成年强制各自保留独立入口说明和出口反馈；亲密直通提交成功后会进入独立反馈事件，明确展示亲密路线已经生效。若强制分支目标有护卫，且护卫设置允许其阻拦，内层说明会提前提示可能遭护卫阻拦。

强行开战后，事件包默认复制原生「袭击」的护卫处理：先用 `EventHelper.HasGuard` 和 `EventHelper.PrepareCombatEnemy(..., noGuard: false)` 准备敌方队伍；若护卫顶在队首，会先进入护卫出面事件，再与护卫开战并回到情难自已结算；若没有护卫、目标本人仍在队首，或设置关闭了护卫阻拦，则直接走正式战斗。太吾村民默认不走护卫阻拦，但可以单独开启“村民启用护卫”。战斗反馈会读取原生 `MainEnemyId`：只有实际战斗主敌就是原目标时，才允许按压服目标结算；若只是击败护卫，则按护卫拦截导致强制失败处理。直接与目标开战前，会沿用原生袭击的 `EventHelper.IsCharacterDirectFallenInCombat` 检查；若目标已无力应战，则不启动战斗，直接按强制成功结算并显示独立反馈。只有确认会与目标本人开战时，才按设置调用原生开战戒心效果。战斗结束后读取 `ArgBox["CombatResult"]`，并以原生 `CombatResultType.IsPlayerWin` 判定强制分支是否成功；若原生战斗结果缺失，则只显示结算未完成，不写入失败经历、结仇或好感惩罚。护卫拦截、目标逃走、太吾撤退、目标无力应战、普通失败和目标战斗致死都保留独立反馈文案，并区分太吾村民与是否结仇。

### 后端接口

前端或其他 Mod 可以调用 `ForceEncounter.ExecuteForcedAction`：

| 参数 | 类型 | 说明 |
|------|------|------|
| `ActorId` | int | 兼容保留；不传时默认太吾，传入时必须等于太吾 |
| `TargetId` | int | 目标角色，必填 |
| `ResolutionMode` | int | 1 为试探/亲密直通判定，2 为战斗结果结算，3 为亲密直通提交 |
| `BattleSucceeded` | bool | 战斗结果；`ResolutionMode = 2` 时由事件包根据 `CombatResult` 传入 |

强行开战后的结算逻辑复用正式版 `DomainManager.Character.HandleRapeAction` 的关键副作用：`MakeLove(..., isRape: true)`、rape 成功/失败经历、rape 密闻和好感变化；原本的战力比较替换为正式战斗结果，结仇改走 `EventHelper.ApplyRelationBecomeEnemy` 以保留原生关系副作用。当前后端只支持太吾作为行为者；成功要求目标不是太吾且战斗成功；生育力不再阻止成功，只由正式版 `MakeLove` 后续影响怀孕。

强制关系实际与目标本人开战时，默认按原生袭击路径增加目标戒心。强行成功时执行 `Character.MakeLove(..., isRape: true)`，并按设置写入成功经历、结仇、好感变化和密闻。亲密直通成功也写入成功经历，并按设置决定是否创建密闻，但不会强制结仇；单恋太吾、以及心有所属他人的谷中密友亲密豁免，会按可配置的村民惩罚比例降低目标对太吾好感。失败时按原逻辑写入失败经历，并按设置决定是否对非村民结仇，同时应用好感变化。

## 设置

| 设置 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 启用接口 | 开关 | 开 | 关闭后所有调用失败 |
| 行动力消耗天数 | 滑条 | 5 | 内层提交消耗的行动力天数，范围 0..5；0 不消耗也不显示成本 |
| 强制好感惩罚 | 滑条 | 30000 | 普通强制路线对目标的好感惩罚；太吾村民和部分亲密豁免按“村民惩罚比例”计算 |
| 村民惩罚比例 | 滑条 | 30 | 太吾村民强制路线、单恋太吾和部分谷中密友亲密豁免使用的好感惩罚比例，范围 0..100% |
| 开战增加戒心 | 开关 | 开 | 进入强制战斗时调用原生敌对开战戒心效果 |
| 启用护卫阻拦 | 开关 | 开 | 目标有护卫时，强制路线先由护卫出面阻拦 |
| 村民启用护卫 | 开关 | 关 | 开启后，太吾村民也会按护卫阻拦规则处理 |
| 强制路线结仇 | 开关 | 开 | 普通强制成功或失败后，对非太吾村民目标调用原生结仇路径 |
| 强制成功创建秘闻 | 开关 | 开 | 强制路线成功后创建原生强制关系秘闻 |
| 亲密成功创建秘闻 | 开关 | 开 | 亲密直通提交成功后创建原生强制关系秘闻 |
| 允许未成年 | 开关 | 开 | 关闭后，未成年角色不会显示情难自已交互项 |
| 调试模式 | 开关 | 开 | 输出后端日志 |

## 限制

- 行为者与目标必须存在、存活且不是婴儿；未成年默认会在内层提交选项给出警告，但不阻止玩家自由。关闭“允许未成年”后，未成年角色不显示内置互动项；后端直接调用仍保留。
- 目标不能是太吾；玩家控制的行为者固定是太吾。
- 内置 UI 是“太吾 -> 互动目标 NPC”的敌对互动选项。
- 后端战斗结算接口需要调用方传入正式战斗或等价系统得到的 `BattleSucceeded`。
- 外层和试探阶段不消耗行动力；内层提交会消耗正式版敌对行为成本，选择“其他话题”不会消耗行动力，也不会写失败记录。

## 验证

1. 构建并部署 `ForceEncounter` 后启动游戏，确认 Mod 设置里有“启用接口”“行动力消耗天数”“强制好感惩罚”“村民惩罚比例”“开战增加戒心”“启用护卫阻拦”“村民启用护卫”“强制路线结仇”“强制成功创建秘闻”“亲密成功创建秘闻”“允许未成年”“调试模式”。
2. 进入存档，找一个存活非婴儿 NPC，打开互动菜单的“敌对”子项，应能看到“情难自已”。
3. 对普通成年 NPC 点击“情难自已”后，应出现“太吾对目标情难自已”的内层说明，并看到“对方似乎并无意向”的内层提交选项。
4. 选择“其他话题”应回到敌对话题页，不进入战斗、不写失败记录、不结仇。
5. 对未成年非婴儿 NPC 点击“情难自已”后，应直接进入同一组内层提交选项，并在说明文本中看到未成年警告，而不是先出现额外确认页。
6. 重新读档或换目标，选择“强制关系”，战斗胜利后返回地图，检查目标人物经历、关系、戒心和密闻：应出现成功记录、结仇、好感下降、戒心变化。若目标有护卫且护卫设置允许阻拦，强制分支内层说明应提前提示可能遭护卫阻拦；若护卫会顶到战斗队首，应先看到护卫出面，再与护卫开战，战斗结束后仍回到情难自已反馈页。太吾村民默认即使有护卫也直接与目标开战，开启“村民启用护卫”后才走护卫阻拦。
7. 在战斗中失败或逃跑，检查目标人物经历和关系：应出现失败记录、结仇、好感下降，且不应发生成功分支。
8. 对配偶、双向恋人、目标单恋太吾、太吾村民或符合条件的谷中密友点击“情难自已”，应在亲密判定通过时进入正常发生关系提交分支；提交后进入亲密反馈事件，不进入战斗、不强制结仇。单恋太吾、以及心有所属他人的谷中密友亲密豁免，应看到目标对太吾好感按折扣降低。
