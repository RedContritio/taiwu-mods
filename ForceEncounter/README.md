# 情难自已 ForceEncounter

为玩家提供一个正式版接口，在互动菜单里主动发起一场正式战斗，并用战斗结果结算角色之间的强制行为。

## 功能

### 敌对互动选项

通过正式版事件包和 `InteractionEventOption` 配置，在角色互动菜单的「敌对」子项中加入「情难自已」。选择目标 NPC 后，默认以太吾为行为者、当前 NPC 为目标，走 `EventHelper.StartCombat` 发起正式战斗。

战斗结束后，事件包读取 `ArgBox["CombatResult"]`。玩家获胜、敌人逃跑或敌人死亡视为战斗成功；玩家失败、逃跑或死亡视为战斗失败。

### 后端接口

前端或其他 Mod 可以调用 `ForceEncounter.ExecuteForcedAction`：

| 参数 | 类型 | 说明 |
|------|------|------|
| `ActorId` | int | 行为者；不传时默认太吾 |
| `TargetId` | int | 目标角色，必填 |
| `AllowTaiwuAsTarget` | bool | 是否允许太吾成为目标 |
| `BattleSucceeded` | bool | 战斗结果；通常由事件包根据 `CombatResult` 传入 |

结算逻辑复制正式版 `DomainManager.Character.HandleRapeAction` 的成功/失败分支，但把原本的战力比较替换为正式战斗结果。成功仍要求目标不是太吾且行为者生育力大于 50。

成功时执行 `Character.MakeLove(..., isRape: true)`，并按原逻辑写入成功经历、结仇、好感变化和密闻。失败时按原逻辑写入失败经历、结仇和好感变化。

## 设置

| 设置 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 启用接口 | 开关 | 开 | 关闭后所有调用失败 |
| 允许太吾成为目标 | 开关 | 关 | 避免误把太吾作为目标 |
| 调试模式 | 开关 | 关 | 输出后端日志 |

## 限制

- 行为者与目标必须存在、存活且为成年人。
- 默认不允许目标是太吾。
- 内置 UI 是“太吾 -> 互动目标 NPC”的敌对互动选项。
- 后端结算接口需要调用方传入正式战斗或等价系统得到的 `BattleSucceeded`。

## 验证

1. 构建并部署 `ForceEncounter` 后启动游戏，确认 Mod 设置里只有“启用接口”“允许太吾成为目标”“调试模式”三个开关。
2. 进入存档，找一个存活成年 NPC，打开互动菜单的“敌对”子项，应能看到“情难自已”。
3. 点击“情难自已”后应进入正式战斗界面，而不是立即结算。
4. 战斗胜利后返回地图，检查目标人物经历、关系和密闻：应出现成功记录、结仇、好感下降。
5. 重新读档或换目标，在战斗中失败或逃跑，检查目标人物经历和关系：应出现失败记录、结仇、好感下降，且不应发生成功分支。
