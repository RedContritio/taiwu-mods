# 情难自已 ForceEncounter

为玩家提供一个正式版接口，在互动菜单里主动触发角色之间的强制行为。

## 功能

### 敌对互动选项

通过正式版事件包和 `InteractionEventOption` 配置，在角色互动菜单的「敌对」子项中加入「情难自已」。选择目标 NPC 后，默认以太吾为行为者、当前 NPC 为目标。

外层选项标记为「唯我」以保持敌对菜单风格，并只展示、校验 5 天行动力成本；它通过原生 wait-confirm 机制延迟外层行为效果，因此点击进入内层时不会立刻扣心情。真正消耗发生在内层提交选项。点击后会先判定当前关系是否可以不进入战斗。内层说明会显示“行为者对目标情难自已”的动作摘要。配偶或双向恋人、双向好感足够、且性格阈值通过时，会进入正常发生关系的内层提交分支。若不能直通，会进入强制关系的内层提交分支：玩家可以选择强行开战，也可以回到其他话题。特殊年龄段不会多一层确认，也不会改变内层选项，只会替换内层说明文本。若强制分支目标有护卫，内层说明会提前提示可能遭护卫阻拦。

强行开战后，事件包复制原生「袭击」的护卫处理：先用 `EventHelper.HasGuard` 和 `EventHelper.PrepareCombatEnemy(..., noGuard: false)` 准备敌方队伍；若护卫顶在队首，会先进入护卫出面事件，再与护卫开战并回到情难自已结算；若没有护卫或目标本人仍在队首，则直接走正式战斗。战斗结束后读取 `ArgBox["CombatResult"]`。玩家获胜、敌人逃跑或敌人死亡视为战斗成功；玩家失败、逃跑或死亡视为战斗失败。

### 后端接口

前端或其他 Mod 可以调用 `ForceEncounter.ExecuteForcedAction`：

| 参数 | 类型 | 说明 |
|------|------|------|
| `ActorId` | int | 行为者；不传时默认太吾 |
| `TargetId` | int | 目标角色，必填 |
| `ResolutionMode` | int | 1 为试探/扣成本/亲密直通判定，2 为战斗结果结算 |
| `BattleSucceeded` | bool | 战斗结果；`ResolutionMode = 2` 时由事件包根据 `CombatResult` 传入 |

强行开战后的结算逻辑复制正式版 `DomainManager.Character.HandleRapeAction` 的成功/失败分支，但把原本的战力比较替换为正式战斗结果。成功要求目标不是太吾且战斗成功；生育力不再阻止成功，只由正式版 `MakeLove` 后续影响怀孕。

强制关系提交时按原生袭击路径增加目标戒心。强行成功时执行 `Character.MakeLove(..., isRape: true)`，并按原逻辑写入成功经历、结仇、好感变化和密闻。亲密直通成功也写入成功经历和密闻，但不会强制结仇或扣除 `-30000` 好感。失败时按原逻辑写入失败经历、结仇和好感变化。

## 设置

| 设置 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 启用接口 | 开关 | 开 | 关闭后所有调用失败 |
| 调试模式 | 开关 | 开 | 输出后端日志 |

## 限制

- 行为者与目标必须存在、存活且不是婴儿；非成人特殊年龄段会在内层提交选项给出警告，但不阻止玩家自由。
- 目标不能是太吾；玩家控制的行为者固定是太吾。
- 内置 UI 是“太吾 -> 互动目标 NPC”的敌对互动选项。
- 后端战斗结算接口需要调用方传入正式战斗或等价系统得到的 `BattleSucceeded`。
- 外层和试探阶段不消耗行动力；内层提交会消耗正式版敌对行为成本，选择“其他话题”不会消耗行动力，也不会写失败记录。

## 验证

1. 构建并部署 `ForceEncounter` 后启动游戏，确认 Mod 设置里只有“启用接口”“调试模式”两个开关。
2. 进入存档，找一个存活非婴儿 NPC，打开互动菜单的“敌对”子项，应能看到“情难自已”。
3. 对普通成年 NPC 点击“情难自已”后，应出现“太吾对目标情难自已”的内层说明，并看到“对方似乎并无意向”的内层提交选项。
4. 选择“其他话题”应回到敌对话题页，不进入战斗、不写失败记录、不结仇。
5. 对特殊年龄段非婴儿 NPC 点击“情难自已”后，应直接进入同一组内层提交选项，并在说明文本中看到特殊年龄警告，而不是先出现额外确认页。
6. 重新读档或换目标，选择“强制关系”，战斗胜利后返回地图，检查目标人物经历、关系、戒心和密闻：应出现成功记录、结仇、好感下降、戒心变化。若目标有护卫，强制分支内层说明应提前提示可能遭护卫阻拦；若护卫会顶到战斗队首，应先看到护卫出面，再与护卫开战，战斗结束后仍回到情难自已反馈页。
7. 在战斗中失败或逃跑，检查目标人物经历和关系：应出现失败记录、结仇、好感下降，且不应发生成功分支。
8. 对配偶或双向恋人、双向高好感目标点击“情难自已”，应在亲密判定通过时进入正常发生关系提交分支；提交后直接成功，不进入战斗、不强制结仇。
