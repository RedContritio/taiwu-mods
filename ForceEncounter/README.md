# 情难自已 ForceEncounter

让太吾也能像 NPC 一样，对看中的目标主动发起强制或亲密行为。

## 这个 Mod 做什么

在角色互动里加入「情难自已」：太吾可以对目标（普通 NPC，或已被你关押的俘虏）主动出手。两情相悦时顺势成事；否则你可以选择强行，或就此作罢。

## 怎么用

- **普通目标**：地图上点开某个 NPC → 互动菜单的「敌对」子项 → 「（情难自已……）」。
- **已关押目标**：打开俘虏面板 → 对某个俘虏点「互动」→ 「（情难自已……）」。

点开后，游戏先判断你和目标是否「情投意合」：

- **情投意合** → 选「（半推半就……）」，两情相悦、直接成事，**不结仇**。
- **否则** → 内层给你两个选择：
  - 「（更进一步……）」= 强行。对普通目标会进入正式战斗；对**已关押的俘虏**因其已被制服、无力反抗，**不再开战、直接得手**。
  - 「其他话题」= 作罢。不消耗行动力、不开战、不结仇、不留记录。

未成年目标默认也能选（说明里会给出提示），可在设置里关闭。

## 亲密直通（情投意合）怎么判定

是否算「情投意合」（走亲密、不结仇），由**两点同时满足**决定：

**1. 关系够格**——目标是下列任一：

- 太吾的**配偶**
- 与太吾**双向爱慕**
- **单恋太吾**（目标爱慕太吾）
- **谷中密友**（带「谷中密友」特性、且是太吾的谷中密友）
- **太吾村民**

**2. 目标对太吾的好感达到「热忱」及以上**

只看**目标对太吾**的好感——也就是你能通过送礼、互动去培养的那一侧；达到「热忱」档即可。**不看太吾对目标的好感，也不受性格影响。**

好感档位由低到高：陌路 → 冷淡 → 融洽 → **热忱** → 喜爱 → 亲密 → 不渝。

两点都满足即亲密直通；否则落到强制路线（或作罢）。

### 亲密成功后的好感惩罚

亲密路线成功都**不结仇**，好感惩罚分三档：

- **配偶 / 双向恋人**：无好感惩罚。
- **单恋太吾 / 已另有所属的谷中密友**：按「村民惩罚比例」打折后的好感惩罚。
- **太吾村民 / 无所属的谷中密友**：无好感惩罚。

## 强制路线

不满足亲密直通时，选「更进一步」强行：

- **普通目标**：进入正式战斗，按战斗胜负结算。目标有护卫时可能被护卫拦下（可在设置里开关；太吾村民默认不被拦）。目标已无力应战时直接判成功。
- **已关押目标**：无需再战，直接按「已制服」判定成功，并保留关押状态。
- 强制**成功**默认会**结仇**并降低目标好感（太吾村民不结仇、好感按比例打折，均可配置）；**失败**则按失败记录处理。

## 设置

Mod 的启停由游戏「模组管理」负责。以下是「模组设置」里的可调项：

| 设置 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 行动力消耗天数 | 滑条 | 5 | 出手时消耗的行动力天数；设为 0 则不消耗 |
| 强制好感惩罚 | 滑条 | 30000 | 强行发生关系后，目标对太吾的好感惩罚 |
| 村民惩罚比例 | 滑条 | 30 | 对太吾村民、单恋太吾者等的好感惩罚折扣（%）|
| 开战增加戒心 | 开关 | 开 | 强行开战时按袭击增加目标戒心 |
| 启用护卫阻拦 | 开关 | 开 | 强行发生关系可能被护卫拦截 |
| 村民启用护卫 | 开关 | 关 | 开启后太吾村民也会被护卫拦截 |
| 强制路线结仇 | 开关 | 开 | 强行发生关系会导致结仇 |
| 强制成功创建秘闻 | 开关 | 开 | 强行发生关系后会产生秘闻 |
| 亲密成功创建秘闻 | 开关 | 开 | 情投意合后会产生秘闻 |
| 允许未成年 | 开关 | 开 | 关闭后，未成年角色不显示「情难自已」|
| 调试模式 | 开关 | 关 | 输出后端日志，排查问题用 |

## 说明

- 行为者固定为太吾；目标不能是太吾，也不能是婴儿。
- 「其他话题」永远是无副作用的退出：不消耗行动力、不开战、不结仇、不留记录。
